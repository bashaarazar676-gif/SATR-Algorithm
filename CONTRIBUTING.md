🤝 Contributing to SATR
First off, thank you for considering contributing to SATR! It's people like you who make the open-source community such an amazing place to learn, inspire, and create.

📜 Code of Conduct
By participating in this project, you agree to abide by our terms: be respectful, professional, and supportive of all contributors.

🛠 How Can I Contribute?
1. Reporting Bugs 🐛
If you find a bug, please open an Issue and include:

A clear description of the problem.

Steps to reproduce the issue.

Any error logs or screenshots.

2. Suggesting Enhancements ✨
Have an idea to make SATR faster or better? Open an Issue with the tag enhancement and describe your vision.

3. Pull Requests (PRs) 🚀
If you're ready to contribute code, follow these steps:

Fork the repository.

Create a new branch: git checkout -b feature/your-feature-name.

Make your changes and ensure the code is clean.

Commit your changes: git commit -m 'Add some amazing feature'.

Push to the branch: git push origin feature/your-feature-name.

Open a Pull Request and describe what you've done.

🎯 Current Focus Areas (Join us!)
We are particularly looking for help with:

Performance Optimization: Making the triangulation logic faster for 4K images.

UI/UX: Building a web-based dashboard for the algorithm.

Math Refinement: Improving the Gouraud Shading interpolation for extreme gradients.

🎨 Style Guide
We follow PEP 8 for Python code.

Please use descriptive variable names (e.g., edge_density instead of ed).

Add comments to explain complex mathematical logic.
